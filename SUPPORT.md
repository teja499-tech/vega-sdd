# Support

Vega SDD is an alpha open-source project maintained on a best-effort basis.

## Usage questions

Before opening an issue:

```bash
sdd --version
sdd doctor
sdd status
```

Search the [documentation](docs/README.md) and [existing issues](https://github.com/teja499-tech/vega-sdd/issues). If the answer is not there, open an issue and include:

- what you are trying to accomplish;
- the exact command you ran and the redacted output;
- Vega SDD, Python, operating-system, and agent-CLI versions;
- project kind and selected adapter;
- a minimal reproduction, when possible.

Never include credentials, private source code, customer data, or unredacted agent transcripts.

## Defects and feature ideas

Use the repository's bug-report or feature-request form. Reproducible examples and clearly stated expected behavior make issues easier to act on. Large changes should be discussed before implementation.

## Security and conduct

Report vulnerabilities privately by following [SECURITY.md](SECURITY.md). Report community-conduct concerns through the private route described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Do not disclose either in a public issue.
